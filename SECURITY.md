# Security Policy

## Reporting Vulnerabilities

If you discover a potential security vulnerability within this repository or live portfolio website, please report it responsibly.

### How to Submit a Security Report

- **Email**: Send details directly to `coloradolevi10@gmail.com`
- **Please Include**:
  - Description of the issue or vulnerability
  - Steps to reproduce the problem
  - Impact assessment

Please allow up to 48 hours for a response before publicly disclosing any details. Thank you for helping keep this project safe!
